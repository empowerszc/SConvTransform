术语表

所有缩写、tile 参数与测量口径，一页讲清。

术语 01

Tile 与循环

Nwin

空间窗口 tile

沿输出空间位置切出的窗口数，直接成为 GEMM 的 m。单线程偏好 160（摊销打包），多核偏好小值（任务更多）。

Nf

filter tile

一次微内核处理的输出通道数，即 GEMM 的 n。实测 {16,32} 即最优，继续放大无单调收益。

Nc

输入通道 tile

归约维上的通道块，决定 k = Nc·Fh·Fw。它把一次 GEMM 的 k 从 54 拉到 144–288，摊薄固定开销。

窗口组 / K3

tiling 分组

tileUsingSCF 按 K3 对窗口做二级分组；K3 随 Nwin 重算，是调度翻转的导火索之一。

并行宽度

parallel width

窗口 tile 循环的 trip count（每个并行区的任务数）。M3 只有 5–20，M4-c 提到 10–40；宽度决定多核收益上限。

术语 02

调度

IS / WS

input/weight-stationary

CSA 的两种打包方向：输入驻留或权重驻留。Nwin 变化可能让同一形状从 IS 翻到 WS，并行时间反而 2 倍。

CSA

cache-aware schedule

纯 cache 代价模型，给出 Nc/K2/K3 与 schd。M4-c 用它探测候选 Nwin 是否翻转调度。

调度保护

schedule guard

M4-c 的规则：CSA(base).schd != CSA(candidate).schd 时保留 base。c1/c2/c9 因此保持 160。

并行链

parallel chain

sconv-parallelize 只折叠「直接嵌套且写不相交」的已标记循环；含共享 scratch 的循环不入链。

per-thread scratch

私有槽

并行区内的打包 buffer 扩成 [64][...]，按 omp_get_thread_num() 取槽，整轮复用。

术语 03

硬件与 roofline

SVE

可伸缩向量扩展

128-bit 向量。2.0 GHz 下单核 SVE 峰值 ≈128 GF；custom_0/9 已到 99–100%。

SME

可伸缩矩阵扩展

矩阵引擎（2×4 tile 累加器）。只喂 c9/c10 这类能铺满 16×16 的形状；扩面实测全面更慢。

打包 roofline

13 GB/s/core

标量 / memcpy / 合并写三写法同速 ⇒ 带宽上限，不是代码上限。

单 NUMA

node0 绑定

多核全部在 numactl --cpunodebind=0 --membind=0 下测；t≥35 是本机慢模式，不作结论。

KBLAS

微内核库

GEMM 微内核来源；超出 SVE 口径的吞吐来自其内部对 SME 的使用。

术语 04

方法与口径

算法时间 / ABI 时间

accounting

tensor→memref 边界拷贝、输出清零等不属于卷积算法；roofline 不同，必须分开计。

差分分解

differential timing

删掉某个调用再相减。陷阱：DCE 会连带删除、未初始化内存引入非规格化数；只能删输出端。

同二进制 A/B

interleaved runs

同代码只切目标机制、交错 3–6 轮取中位数、未改动用例作噪声底线（±4–7%）。

best-of / geomean

aggregation

性能取多轮最小/最佳档；跨形状用几何平均，避免被单一大形状支配。

门禁

gates

test_fastpack / test_mk_auto / test_multicore 三层：IR 结构、数值一致、性能阈值。

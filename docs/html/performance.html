性能 05

观测到的三个口径问题

t≥35 是慢模式

node0 有 38 核，但 t≥35 稳定进入不可复现慢模式；线程扫描截到 t32。

GFLOPS 曾漏乘 batch

旧公式漏了输出 batch，batch=4 时 GF 被低估 4×；ms 与加速比不受影响，脚本已修复。

调优是噪声决策器

同一形状跨进程可能选到不同参数；不要用单次运行比较两个版本。

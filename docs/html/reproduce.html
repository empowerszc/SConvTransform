复现 02

单线程与多核

单线程bash
python3 scripts/convbench/run_convbench.py \
  --csv scripts/convbench/samples/custom_conv.csv \
  --transform test/lowering/sconv-blas-fastp.mlir \
  --num 11 --runs 5 --warmup 3
多核（M4-c）bash
build/bin/sconv-opt \
  -transform=test/lowering/sconv-blas-fastp-mc.mlir \
  -sconv-parallelize -sconv-lower-parallel \
  conv.mlir -o conv.mc.llvm.mlir

OMP_NUM_THREADS=16 numactl --cpunodebind=0 --membind=0 \
  $LLVM/bin/mlir-cpu-runner conv.mc.llvm.mlir \
  -e main -entry-point-result=void \
  -shared-libs=...,libomp.so
复现 03

门禁：每一层都有失败测试先行

构建 → ir → auto → correct → perf；任一层失败就回退改动
门禁阶段检查什么当前结果
test_fastpack.pyir / correct / perf输入打包替换为 pack_input_tile；逐元素一致；custom_0 ≤55 msPASS（40.3 ms）
test_mk_auto.pyir / perfauto IR == 显式 IR；11 形状性能PASS
test_multicore.pyir / auto / correct / perfmarker 标对窗口循环；Nwin 表；调度不翻转；5 形状正确；custom_0 t16 ≤24 msPASS（19.5 ms）

ir

显式 pin Nwin，检查并行循环的 step 等于 Nwin；覆盖两种 tiling 顺序。

auto

11 形状的 Nwin 表 + CSA 调度一致性；c1/c2/9 必须保持 160。

correct

5 形状覆盖私化与共享两条 scratch 路径；另有 11/11（t8/t32）全量复核。

复现 04

预期结果（2.0 GHz）

单线程

custom_0 33.3 ms / 127.7 GF；11 形状 geomean 1.57× vs torch t1。

多核（M4-c）

custom_0 t16 15.8 ms；geomean 2.51×；最高 386 GF（custom_4 @t32）。

注意：共享节点噪声约 ±4–7%；不要用单次运行比较两个版本。 线程数 ≤32；t≥35 的慢模式不作为结论。
